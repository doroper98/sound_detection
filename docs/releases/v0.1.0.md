# v0.1.0 — 2026-09-22

SoundField Lab의 첫 가상 음향 실험 버전입니다.

## 추가

- 가구가 있는 8 × 7 × 3.2 m 공간과 클릭·좌표 기반 음원 배치, 회전·확대.
- 휴대폰 시야의 드래그/방향키 회전, 표면 음압과 마이크 위치 적합도 열지도.
- 볼륨 40~100 dB @1m, 주파수 100~8000 Hz, 음속과 연동한 파장.
- 마이크 1~2개, iPhone 15 Pro / iPad Pro 11″ / Galaxy S24 가상 프리셋 및 사용자 간격 2~200 cm.
- 최대 12개 관측, 20 cm 격자 탐색, 광대역 시간차·단일 주파수 위상 모호성 비교.
- 정현파 미리듣기, 초기화, 버전 포함 JSON 내보내기, 한국어 가이드.
- 요구사항·개발 로그·정규 문서, 자동 Gate, 태그 기반 GitHub 릴리즈, Cloudflare 설정.

## 검증

- TypeScript strict 검사 및 프로덕션 빌드 통과.
- Cloudflare Workers 배포: https://soundfield-lab.monosound09.workers.dev
- 음향 모델 테스트 9개 통과. 다른 위치·높이·방향의 4개 합성 관측에서 테스트 기준 오차 21 cm 미만.
- Chromium E2E 2개 통과: 클릭, 음향 연동, 드래그, 단일 마이크 제약, 관측 초기화, 프리셋, 다운로드, 모바일 넘침, 열지도 픽셀, 가이드.
- 실제 스마트폰 하드웨어 정확도와 Safari는 아직 검증하지 않았습니다.

## 알려진 제한

- 실제 수음이 아닌 가상 시뮬레이터입니다. 기종 프리셋은 실측 마이크 사양이 아닙니다.
- 자유 음장/음속 343 m/s, 고정 음원, 정확히 알려진 마이크 위치·방향, 동기화된 합성 시간차를 가정합니다.
- 벽 반사·차폐·회절·장치 잡음을 포함하지 않습니다. 적합도 폭은 단순 불확실성 모델입니다.
- 1개 마이크에는 방향 정보가 없고 2개의 단일 관측에는 여러 위치 후보가 남습니다.
- 열지도는 보이는 표면을 평가하므로 공중 음원의 최대 적합도가 화면에 보이지 않을 수 있습니다.
- 원격 배포 및 재배포 절차는 docs_canonical/DEPLOYMENT.md를 확인하세요.
