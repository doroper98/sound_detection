# v0.2.0 — 2026-09-22

3D 화면과 독립된 PCM 음향 엔진, 카메라 위 소리 표시, 한 화면 실험 UI.

## 변경

- `@soundfield/localization` 패키지 분리. 마이크 PCM/샘플링/배치만으로 GCC-PHAT 또는 순음 위상을 측정하고 위치 후보를 탐색합니다.
- 앱도 합성 PCM을 실제 엔진에 통과시키며, 좌표에서 계산한 정답 시간차를 추정기에 직접 넣던 경로를 제거했습니다.
- 추정 엔진은 React, Three.js, 방 크기, 물체, 카메라, 음원 정답 위치를 받지 않습니다. 탐색 범위는 호출하는 앱의 명시적 입력입니다.
- 웹 화면 없이 실행하는 JSON replay 예제와 배포 가능한 JavaScript/타입 선언 패키지를 제공합니다.
- 좌우·세로 마이크 배열 선택. 좌우 방위/고도에 대한 감도 차이를 실험할 수 있습니다.
- 추정 열지도를 카메라 영상에 직접 겹칩니다. 두 마이크의 후보 띠를 숨기지 않고, 별도 ‘정답 비교’에서만 설정 위치를 표시합니다.
- 데스크톱은 전체 페이지 스크롤 없이 설정/관측 탭을 사용합니다. 모바일은 공간/스캔 탭과 미리보기를 유지하는 하단 설정 패널을 제공합니다.
- Pages 배포 설정 준비. 계정명이 없는 주소로의 전환은 Pages 추가 권한 승인 대기입니다.

## 검증

- 물리/PCM/독립성 테스트 21개 통과: 부호가 다른 지연 추출, 무음/비동기 거부, 3D 좌표 변경 독립성, 임의 좌표계, 배열 방향.
- Chromium 데스크톱/모바일 E2E 2개 통과. 페이지 가로/세로 넘침 없음, 탭 전환, 동시 미리보기/설정, 마이크 배열, 관측, PCM 내보내기 확인.
- 실제 모바일 하드웨어 입력과 Safari 검증은 아직 수행하지 않았습니다.
- SDK tarball을 별도 consumer에 설치/import하고 CLI replay의 정답 좌표 변경에 대한 출력 불변성을 검증했습니다.

## 제한

- 웹 앱 입력은 합성 PCM이며 실제 마이크 캡처는 포함하지 않습니다. 앱용 엔진은 실제 동기화 PCM을 받을 수 있지만 현실 장치 정확도는 검증되지 않았습니다.
- 두 마이크만으로 유일한 3D 위치를 보장하지 않습니다. 다중 pose는 고정 음원과 교정된 마이크 위치를 가정합니다.
- σ와 후보 범위는 휴리스틱이며 확률 신뢰도가 아닙니다. dBFS는 교정된 dB SPL이 아닙니다.
