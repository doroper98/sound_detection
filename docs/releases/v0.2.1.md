# v0.2.1 — 2026-09-22

데시벨에 반응하는 열지도와 계정명 없는 공개 주소

## 변경

- 볼륨을 바꾸면 PCM 수신 레벨에 따라 열지도의 색·불투명도·표시 범위가 변합니다. 정답 비교와 마이크 추정 모두 적용됩니다.
- 자동 정규화 없이 −85~−30 dBFS 고정 척도를 사용합니다. 추정 방향 계산은 독립 엔진을 유지합니다.
- 큰 볼륨 입력을 같은 크기로 만들던 가상 센서 이득 제한을 수정했습니다. 실제 샘플 포화는 별도로 표시합니다.
- 휴대폰 화면 안에 수신 dBFS를 표시해 모바일 설정 중에도 확인할 수 있습니다.
- 공개 배포 대상: https://soundfield-lab.pages.dev (계정명 없는 Cloudflare Pages 주소).
- 실제 카메라 영상과 마이크 진단을 연결하는 후속 개발 계획을 문서화했습니다.

## 검증

- TypeScript strict 및 프로덕션 빌드, 단위 테스트 25개.
- 순음/광대역 40~100 dB에서 10 dB 간격의 PCM 레벨 변화와 추정 지연 불변 확인.
- 데스크톱/모바일 4개 브라우저 시나리오: 두 열지도 모드의 50→90→50 dB 색·면적 변화/복원, 화면 내 미리보기와 기존 기능.
- 최신 배포 검증 결과는 docs_canonical/DEPLOYMENT.md에 기록합니다.

## 제한

- 표시 면적은 음원의 실제 크기나 위치 정확도가 아닙니다. 표시 점수는 PCM 레벨과 방향 적합도를 결합한 시각화입니다.
- 실제 카메라·마이크 입력은 포함하지 않습니다. dBFS는 실제 SPL로 교정되지 않았습니다.
- 단일 마이크는 방향을 제공하지 않고 두 마이크 한 관측에는 3D 모호성이 남습니다. 실제 iPhone/iPad 하드웨어 검증은 별도입니다.
