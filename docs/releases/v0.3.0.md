# v0.3.0 — 2026-09-22

작은 슬라이더 설정과 실제 카메라·Safari 채널 진단

## 변경

- 실험 설정을 음원·마이크·공간/표시 탭과 슬라이더 위주로 줄였습니다. 데스크톱 설정 높이 225→112px, 모바일 280→174px로 3D와 폰 미리보기 공간을 넓혔습니다.
- /diagnostics에서 실제 후면 카메라와 마이크 진단을 시작할 수 있습니다. 4채널 필수·2채널 필수·기본 입력을 요청하고 브라우저 설정과 Web Audio PCM 채널 수를 별도로 표시합니다.
- 채널별 디지털 음량, 무음·중복 파형 의심, 결과 복사/JSON 저장, 권한 오류와 취소·중지 처리를 추가했습니다. 영상·원음은 서버로 보내지 않습니다.
- 3D 합성 신호의 즉시 표시와 실제 iPhone 성능을 구분하는 설명, 실기기 검사 순서와 방향 추정 확장 계획을 갱신했습니다.

## 검증

- TypeScript·프로덕션 빌드·버전 문서 일치, 단위 테스트 30개와 Chromium 사용자 시나리오 13개를 통과했습니다. 데스크톱/모바일 설정 중 미리보기와 페이지·설정 패널 넘침도 확인했습니다.
- 자동 수음 테스트는 합성 입력입니다. 실제 Chromium의 스트림 변환과 4채널 Web Audio 입력 fixture를 구분합니다. 후자는 실제 마이크 검증이 아닙니다.
- Windows용 Playwright WebKit은 필요한 캡처 API를 제공하지 않아 실제 수음 시나리오를 수행하지 못했습니다. 기능 미지원 안내·진단 저장 시나리오는 통과했습니다.

## 제한

- iPhone 17 Pro Safari 실기기 보고서 미확보. 마이크 4개 장착, 4채널 요청 수락, 실제 PCM 4채널, 물리 센서 독립성은 서로 다른 검증입니다.
- 실제 영상 위 방향 열지도는 아직 없습니다. 물리 센서 위치·동기화·영상 축 교정과 실측 오차 검증 후 연결해야 합니다. 실제 cm 정확도·측정 지연을 보장하지 않습니다.
- dBFS는 디지털 신호 레벨로, 교정된 dB SPL이 아닙니다. 캡처 API가 없으면 기능 미지원 안내와 진단 정보 저장만 제공합니다.
