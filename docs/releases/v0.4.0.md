# v0.4.0 — 2026-09-22

모노 입력에서도 동작하는 실시간 주파수·음량 분석

## 변경

- `/listen`에서 실제 마이크 입력을 연속 분석한다. 채널 선택, 전체/저역/중역/고역, 스펙트럼·전체 RMS·대역 RMS·최대 주파수를 표시한다.
- 카메라를 먼저 켜면 수음과 함께 볼 수 있다. 중지·화면 숨김·페이지 종료·입력 종료·PCM 무응답 시 마이크를 해제한다.
- 원음·영상·장치 ID를 제외한 마지막 분석 통계를 JSON으로 저장한다.
- 사용자 제공 iPhone 17 Pro Safari 결과를 보존하고 Chrome과 동일한 실효 모노 결과를 기록한다.

## 검증

- 단위 테스트 40개 통과: 44.1/48 kHz 순음, 20 dB 진폭 변화, 대역 분리, 무음·DC·포화와 캡처 종료 처리 포함.
- TypeScript strict, 프로덕션 빌드, 버전 메타데이터 및 Chromium E2E 16/16 통과. 화면 조정 뒤 연속 분석 회귀 1/1 추가 통과.
- 390×844/1366×768의 카메라·그래프·분석 수치와 페이지 양축 넘침을 확인했다.

## 제한

- dBFS는 디지털 레벨이며 보정된 dB SPL이 아니다. 주파수로 음원 종류·방향·거리를 판정하지 않는다.
- 실제 iPhone Safari에서 v0.4.0 연속 분석을 재검증해야 한다. 기존 v0.3.0 보고서는 2채널 중 1채널만 활성이다.
- 독립 다채널·센서 위치·시간 동기화·영상 정렬이 확보되지 않아 실제 위치 열지도는 제공하지 않는다.
- Cloudflare 인증 만료로 공개 배포는 대기 중이며 기존 공개 주소에 반영 완료된 버전이 아니다.
