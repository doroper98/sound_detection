# v0.2.1 배포 결과와 실제 카메라 웹앱 안내

2026-09-22 사용자에게 전달한 안내문을 원문으로 보관합니다. 아래 배포·검증 결과는 v0.2.1 기준입니다.

**[웹사이트 접속](https://soundfield-lab.pages.dev)** — v0.2.1 배포했습니다. 주소에 `monosound09`는 없습니다.

- 데시벨을 올리면 열지도의 색이 강해지고 표시 영역이 넓어집니다.
- 위치 추정은 계속 3D 정답 좌표와 독립적으로 작동합니다.
- 단위 테스트 25개, 공개 사이트 데스크톱·모바일 검증 4개 통과했습니다. [릴리즈 노트](https://github.com/doroper98/sound_detection/releases/tag/v0.2.1)

**실제 카메라 웹앱도 가능합니다.** 다음 순서로 개발하면 됩니다.

1. 접속 후 ‘카메라 시작’을 누르고 권한을 허용하면 후면 카메라 영상을 표시합니다. HTTPS와 사용자 권한이 필요합니다. [공식 설명](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
2. 실제 마이크 음량을 측정하고, 브라우저가 제공하는 수음 채널을 확인합니다.
3. 독립된 동기화 마이크 채널이 확보되면 기존 추정 엔진을 연결하고, 카메라 방향과 맞춰 열지도를 겹칩니다.

핵심은 **휴대폰의 여러 마이크를 웹에서 독립적으로 읽을 수 있느냐**입니다. 한 채널만 제공되면 음량은 표시할 수 있지만 방향은 결정할 수 없습니다.

현재 버전은 가상 실험이며, 실제 카메라·수음 연결에 필요한 [개발 계획](https://github.com/doroper98/sound_detection/blob/main/docs_canonical/LIVE_CAMERA_PLAN.md)까지 정리했습니다.
