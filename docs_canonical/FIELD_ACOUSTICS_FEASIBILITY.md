# 야외 음향 탐색: 주파수 지도와 500m 드론 거리 추정

논의·자료 확인: 2026-09-22. 기준 제품: v0.3.0.

후속 v0.4.0: Safari에서도 실효 모노 결과를 확보했고 `/listen`에서 실제 입력의 연속 스펙트럼·선택 대역 음량을 구현했다. 아래 ‘주파수별 위치 지도 미구현’은 여전히 유효하다. 주파수 분석은 드론 탐지·분류·방향·거리 측정 성능 검증이 아니다.

## 주파수별 열지도

동시에 수집한 독립 마이크 PCM을 시간·주파수별로 나누고, 선택 대역에서 센서 간 지연/위상 관계로 방향 적합도를 구한다. 공간 정보가 없는 단일 고정 무지향성 입력은 주파수 스펙트럼·음량을 제공하지만 일반적인 미지 음원의 방향 지도를 만들 근거가 부족하다.

화면은 선택한 주파수 대역의 방향 지도, 주파수 범례, 수신 레벨과 추정 불확실성을 표시하는 방식이 가능하다. 여러 대역을 동시에 표시한다면 색상은 대역, 투명도는 레벨 등 의미를 분리해야 한다. 현재 열지도의 빨간색 강도와 혼동하지 않도록 별도 표시 모드가 필요하다. 음원의 고조파와 넓은 주파수 성분, 서로 겹치는 대역 때문에 주파수 하나를 새/어린이/드론이라는 종류에 고정 배정할 수 없다.

분류기는 별도 문제다. 대역별 지도는 여러 소리의 공간적 분리에 도움을 줄 수 있지만 같은 방향·겹치는 대역의 분리를 보장하지 않는다. 연구의 드론 음향 모듈도 선택한 주파수들의 빔포밍 결과를 합쳐 방향을 추정한다. [Ding 외, 2023, §4.1](https://doi.org/10.1002/aisy.202300251)

## 간격을 구분해야 하는 이유

| 용어 | 의미 | 주로 영향을 주는 것 |
|---|---|---|
| 개별 마이크 간격 | 한 배열 안의 센서 간 거리 | 지연·위상 측정, 주파수별 모호성 |
| 배열의 전체 크기 | 한 관측소의 마이크들이 차지하는 폭 | 방향 구별과 신호 합성 성능 |
| 관측소 간격 B | 방향을 각각 측정하는 장치 사이 거리 | 두 방향을 교차시킬 때 거리 오차의 증폭 |

**마이크 두 개를 100m 떨어뜨리는 것과, 여러 마이크로 방향을 측정하는 관측소 두 곳을 100m 떨어뜨리는 것은 다르다.** 두 마이크의 한 도착 시간차는 하나의 거리 차이이며, 3D에서는 일반적으로 쌍곡면 위에 여러 후보가 남는다. 센서를 늘릴 때도 일렬 배치·평면 대칭 등 퇴화한 배치를 점검해야 한다. [MathWorks TDOA 설명](https://www.mathworks.com/help/fusion/ug/object-tracking-using-time-difference-of-arrival.html)

관측소별 방위·고도각을 교차시키는 방법과, 모든 센서의 도착 시간차를 직접 푸는 방법은 설계가 다르다. 후자는 센서 간 샘플 시각·클록 오차를 교정해야 한다. 전자는 배열 내부 동기화 외에 관측소의 위치·자세와 같은 표적/음원 시점의 관측 정렬이 필요하지만, 관측소끼리 반드시 오디오 위상까지 공유해야 하는 것은 아니다.

단순 균일 배열에서 위상만 이용하면 센서 간격을 파장 절반보다 크게 할 때 공간적 모호성이 생길 수 있다. 따라서 전체 크기만 키우는 대신 센서 수·배치·대역·광대역 처리까지 함께 설계한다. 실제 배열 설계 연구도 주파수별 성능과 센서 배치를 함께 평가한다. [Blass·Graf, 2025](https://dael.euracoustics.org/confs/fa2025/data/articles/000269.pdf)

## 500m, ±50m의 조건부 계산

다음은 **하드웨어 성능 예측이 아닌 순수 기하 계산**이다.

- 두 관측소 A/B는 B만큼 떨어져 있고 위치·기준 방향을 정확히 안다고 가정한다.
- 표적은 두 관측소의 중점에서 기선에 수직인 방향으로 R=500m 떨어져 있다. 관측소와 표적을 포함하는 평면에서 거리 방향의 민감도를 계산한다.
- 각 관측소가 해당 평면의 입사 방향을 실제값의 ±0.5° 안에서 측정한다고 가정한다. 이 값은 실측값·표준편차·95% 신뢰구간이 아니다.
- 기상·굴절·잡음·시계·센서 자세·표적 이동·연산 지연의 추가 오차를 제외한다.

각 관측소에서 기선의 수직 방향과 표적 사이의 각도는 `α=atan(B/(2R))`다. 방향 오차 `δ=0.5°`가 양쪽에서 거리 오차를 키우는 방향으로 발생하는 경우:

```text
R_near = B / (2 tan(α + δ))
R_far  = B / (2 tan(α - δ))   (α > δ인 경우)
```

| 관측소 간격 B | 500m 표적의 계산 거리 범위 | 거리 방향 오차 |
|---|---|---|
| 50m | 425.5~606.0m | −74.5 / +106.0m |
| 100m | 459.5~548.3m | −40.5 / +48.3m |
| 200m | 478.3~523.7m | −21.7 / +23.7m |

따라서 **각 관측소의 방향 오차가 ±0.5° 이내라는 가정 아래, 관측소 간격 약 100m는 목표를 설명하는 계산 예시**다. 실무 최소 간격이나 제품 사양으로 확정할 수 없다. 이 표는 거리 방향의 오차만 계산하며 3D 위치 전체의 ±50m를 보장하지 않는다. 표적이 기선 방향에 가까워지면 방향선 교차 조건이 나빠지고 결과도 달라진다. 배열 내부 마이크 간격을 이 표에서 역산할 수 없다.

작은 각도·B≪R의 범위에서 최악 방향의 거리 오차 크기는 대략 `2 R² δ / B`다(δ는 라디안). 각도 오차가 두 배면 같은 간격의 거리 오차도 대략 두 배다. 근사식을 큰 기선이나 거의 평행한 방향선에 무조건 적용하지 않는다.

재현용 JavaScript(Node.js, 외부 패키지 불필요):

```js
const R = 500;
const delta = 0.5 * Math.PI / 180;
for (const B of [50, 100, 200]) {
  const alpha = Math.atan(B / (2 * R));
  const near = B / (2 * Math.tan(alpha + delta));
  const far = B / (2 * Math.tan(alpha - delta));
  console.log(B, near.toFixed(1), far.toFixed(1));
}
```

## 500m에서 먼저 확인할 것

첫 관문은 드론 소리가 배경 소음과 구분되어 충분히 수음되는가다. 드론 크기·회전수·자세, 바람·곤충·차량·지면 반사 등에 따라 달라진다. 자유 음장의 거리 감쇠만 계산해도 1m에서 500m까지 약 54dB 감소한다. 이것은 대기 흡수나 잡음 바닥을 포함한 탐지 거리 예측이 아니며, 원래 음량을 모르면 수신 음량으로 거리를 역산할 수도 없다.

32채널 배열을 평가한 2025년 논문은 해당 데이터에서 정지/이동 운용의 방향 오차 중앙값을 각각 약 5°/20°로 보고한다. 실험 범위·장비·평가 조건이 다르므로 모든 배열의 한계로 일반화할 수 없지만, 위 계산의 ±0.5°가 저절로 달성되는 조건이 아님을 보여준다. [Blass·Graf, 2025, §4–5](https://dael.euracoustics.org/confs/fa2025/data/articles/000269.pdf)

500m 이상의 3D 추적을 보고한 MUTES 연구는 마이크 256개를 묶은 64채널 배열과 카메라·장거리 라이다를 결합한다. 음향 모듈은 주로 방향을 제공하고 라이다가 거리 정보를 더한다. 해당 연구의 3D 정확도를 마이크 단독 또는 iPhone 성능으로 인용하면 안 된다. [Ding 외, 2023, §3.1·4.2](https://doi.org/10.1002/aisy.202300251)

또한 음속을 343m/s로 놓으면 500m 전파에 약 **1.46초**가 걸린다. 예를 들어 속도가 20m/s라면 그동안 약 **29m** 이동한다. 속도는 설명용 가정이다. 수음으로 추정한 소리 발생 시점의 위치와 화면을 보는 현재 시점의 예측 위치를 구분해야 한다. 관측소마다 전파 시간도 다르므로 이동 표적의 시간 정렬을 다뤄야 한다.

## 단일 마이크 이동과 합성개구

이동하는 센서의 여러 시점 기록을 활용하는 음향 합성개구 연구는 존재한다. 알려진 이동 궤적을 이용해 **정지한 조화 음원**을 추정한 연구가 있다. [Ang 외, 2017](https://www.apsipa.org/proceedings/2017/CONTENTS/papers2017/13DecWednesday/Poster%201/WA-P1.21.pdf)

단일 마이크를 빠르게 원운동시키고 이동이 만드는 신호 변화를 이용해 미지 신호의 방향을 추정한 연구도 있다. 이는 특정 기구·알고리즘으로 얻은 방향 결과이며 500m 이동 드론의 거리 ±50m 검증이 아니다. [Lawrence 외, 2024](https://www.frontiersin.org/journals/signal-processing/articles/10.3389/frsip.2024.1341087/full)

따라서 ‘한 마이크로는 어떤 조건에서도 불가능’이라고 단정하지 않는다. 다만 손으로 휴대폰을 옮긴 기록을 동시 다채널 녹음처럼 취급할 수는 없다. 서로 다른 시점의 소리를 관측하며, 드론 자체의 이동·회전수·위상·방사 특성 변화와 수신기의 이동 효과가 섞이기 때문이다. 일반적인 능동 SAR은 알려진 송신 신호와 센서 궤적을 활용하지만 여기서는 미지의 드론 자체 소리를 수동 수신한다. 같은 처리로 거리를 바로 얻을 수 있다는 뜻이 아니다.

연구 경로는 다음처럼 구분한다.

| 방법 | 필요한 추가 조건 | 현재 판단 |
|---|---|---|
| 단일 마이크 합성개구 | 정확한 센서 궤적, 신호의 시간 변화 모델 또는 기준, 표적 운동 모델과 관측 가능성 검증 | 연구 가능성. 현재 목표 달성 수단으로 검증되지 않음 |
| 배열을 옮겨 방향 관측 누적 | 매 시점의 방향, 센서 위치·자세, 고정 음원 또는 식별 가능한 운동 모델 | 정지 음원부터 별도 실험 가능. 현재 시뮬레이터의 고정 음원 누적과 이동 드론 추적은 다름 |
| 여러 고정 관측소의 동시 관측 | 각 배열의 방향 정확도, 위치·자세 교정, 표적 대응·시간 정렬 | 500m 거리 추정의 조건을 나누어 검증하기 좋은 후보 |
| 음향 + 전용 거리 센서 | 음향 탐지와 다른 센서의 같은 표적 확인, 장비별 유효 거리 검증 | 거리 정밀도가 우선이면 비교할 구조. 휴대폰 내장 센서의 500m 성능을 뜻하지 않음 |

## 검증 순서와 판정 기준 제안

사용자가 확정한 것은 약 500m와 거리 오차 약 ±50m다. 아래 성공률은 **향후 합의할 시험 기준의 제안**이며 사용자 확정 조건이 아니다.

1. **수음 검증:** 대상 드론 기종과 시험 환경을 정하고 거리별 원음·배경 소음을 확보한다. 탐지 성공률과 드론이 없을 때의 오탐을 함께 기록한다. 500m에서 신호를 얻지 못하면 간격 계산으로 해결됐다고 하지 않는다.
2. **방향 검증:** 알려진 음원 위치를 평가용으로만 사용해 각 배열의 방위·고도 오차, 편향, 이상치와 지연을 측정한다. 중앙값만으로 ‘±0.5° 이내’라고 선언하지 않는다.
3. **거리 검증:** 실측 방향 오차를 넣어 관측소 간격·배치별 오차를 계산한다. 유리한 중앙 배치 외에 기선 방향, 다양한 고도·거리에서도 평가한다. 내부 배열 동기화와 관측소 간 시간 정렬을 각각 점검한다.
4. **이동 검증:** 소리 발생 시점 위치와 현재 위치 예측의 오차를 분리한다. 속도 변화·선회 시 예측 실패와 추적 끊김도 포함한다.
5. **합격 정의:** 예를 들어 유효 탐지 중 95%에서 거리 절대오차 50m 이하를 후보로 삼되, 탐지율·가용률·오탐률·갱신 주기·지연을 별도 제시한다. 어려운 프레임을 숨겨 정확도만 높이지 않는다.
6. **화면 연결:** 실측 입력 조건이 검증된 뒤 주파수 대역별 방향 지도와 거리 구간을 연결한다. 근거가 부족하면 위치/거리를 미확정으로 표시하고 숫자나 작은 열점을 임의로 만들지 않는다.

현 시점에는 iPhone 단독으로 500m 드론의 거리를 ±50m로 측정할 수 있다고 말할 근거가 없다. 웹앱은 외부 측정 결과를 시각화하는 화면으로 확장할 수 있지만, 필요한 측정 하드웨어와 데이터 경로는 별도 개발·검증 대상이다.
